# Prompt Engineering Academy

Учебный SPA-портал на `React + Vite + TypeScript`, где теория по prompt engineering сразу закрепляется встроенными упражнениями. Проект закрывает обязательный минимум задания: 3 статьи, 6 типов интерактивных компонентов, итоговый тест на 10 вопросов, общий подсчёт баллов и краткие рекомендации по результату.

## Почему этот стек

- `React` удобен для переиспользуемых интерактивных компонентов с единым API.
- `Vite` даёт быстрый старт, простую сборку и понятную конфигурацию.
- `TypeScript` помогает держать под контролем union-типы упражнений, результатов и общего состояния теста.

## Что реализовано

- Два режима работы компонентов: `inline` и `quiz`.
- Обязательные типы упражнений:
  - `MultipleChoice`
  - `TrueFalse`
  - `FillTheBlank`
  - `MatchPairs`
  - `OrderSteps`
- Кастомный компонент:
  - `PromptBuilder`
- 3 статьи:
  - `Как работают LLM и токены`
  - `Галлюцинации и безопасность`
  - `Структура эффективного промпта: роль, контекст, ограничения`
- Полноценный итоговый тест на 10 вопросов.

## Архитектура

- Все упражнения описываются единым union-типом `ExerciseDefinition`.
- Каждый компонент возвращает результат в формате `ExerciseResult`.
- В `quiz`-режиме результаты собираются через `QuizSessionProvider`, который считает прогресс, баллы, процент и рекомендацию.
- Контент статей описан декларативно: текстовые секции чередуются с встроенными упражнениями.

## Локальный запуск

1. Установить зависимости:

```bash
npm install
```

2. Запустить dev-сервер:

```bash
npm run dev
```

3. Открыть приложение в браузере по адресу, который покажет Vite.

## Как проверить проект

1. На главной странице открыть любую из 3 статей.
2. Пройти встроенные упражнения прямо по ходу текста и посмотреть обратную связь.
3. Перейти в `Итоговый тест`, ответить на вопросы и нажать `Завершить тест`.
4. Убедиться, что отображаются прогресс, процент, баллы и рекомендация.
5. Для автоматической проверки выполнить:

```bash
npm run test
npm run build
```

`npm test` запускает e2e-проверки через `Playwright`. В текущей конфигурации используется локальный Google Chrome.
